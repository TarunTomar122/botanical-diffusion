# exp001 — Baseline 128px (35.7M UNet) — Curtis 360 plates

**Status:** RUNNING (started 2026-08-26 08:56, RTX PRO 4000 Blackwell $0.57/hr)

## Hypothesis
A 35.7M pixel-UNet trained from scratch on 360 Curtis plates at 128×128 can learn coherent
botanical plate structure (cream paper, centered habit, petals/leaves, dissections) — and the
progression noise → structure → petals → plates will be visible in samples.

## Config
- `configs/baseline_gpu_128.yaml`: UNet 35.7M, 4 blocks (128,256,256,256), attn@16, dropout 0.1
- DDPM 1000 steps, eps prediction, batch 8, EMA 0.9999, AdamW 1e-4 cosine (warmup 500)
- 50k steps total, checkpoint 2k, samples 1k, seed 42, fp32 (no AMP), center crop + hflip only
- Data: `data/processed/curtis-128` 360 plates (9 vols, top 40/vol)

## Hardware / Cost
- RTX PRO 4000 Blackwell 24GB ($0.57/hr secure), 3.5 it/s → 50k steps ≈ 4h ≈ $2.28
- Sanity run (exp000, 64px 12M, 1500 steps) cost ~$0.01 before this
